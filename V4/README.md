# When Familiar Becomes Overwhelming — Sensory v4

本版只使用你提供的新版走廊模型，保留已经纠正的方向：从 Z≈77 的正常走廊开始，向 Z≈-18 的过载终点前进。

## v4 新增：耳鸣与后段扭曲

- 中段逐渐出现细长的耳鸣高音；后段再加入第二层更细的高音，伴随缓慢的音高与响度起伏。
- 耳鸣与走廊声音分开混音，声音更像来自耳内；结尾会渐渐消退，也受右下角总音量与 M 静音控制。
- 后段增加缓慢的镜头边缘弯曲、轻微倾斜、不对称挤压，以及小幅视野收放。人物真实位置、空气墙与互动检测不受画面扭曲影响。
- 耳鸣参数在 `js/soundscape.js` 顶部 `SOUND.ringing`；扭曲参数和中文说明在 `js/sensory-fx.js` 的 02 区块；视野起伏在 `js/app.js` 的行走区块。

## 保留的渐进体验

1. 去掉电视雪花、扫描线、横向信号撕裂和 RGB 分色。
2. 视觉改为日常走廊逐渐失焦、同色轮廓重叠、边缘缓慢变形、亮部眩光扩大，让前景与背景越来越难区分。
3. 加入真实的大厅交谈录音与瓷砖走廊脚步录音。开头只有两层远处声音，随后更多方向的交谈和脚步加入，逐渐达到七层；声音清晰度和回声也一起增强。
4. 玩家自己的脚步和背景路人脚步分开：自己停下来后，路人的交谈与脚步仍然存在。
5. 后段白色过曝随路线进度平缓增加，不再周期性忽明忽暗。穿过最后一道门后，约 4 秒到达全白，停留约 1.2 秒，再用约 5 秒逐渐退去，露出安静空间。
6. 保留四个依次触碰的互动点、亮灯引导、门解锁、空气墙、长椅碰撞与有惯性的行走。
7. 在重要代码区块上方加了中文说明；常改参数集中在配置区域。

## 启动

完整解压到一个新的文件夹，然后双击 `START_WINDOWS.bat`（需要电脑安装 Python），保留终端窗口。浏览器地址是 `http://localhost:8000`。

如果之前的 demo 还在使用 8000 端口，先关闭旧终端中的服务器，再启动新版，避免又打开旧项目。也可以在 VS Code 中打开本版文件夹，对 `index.html` 使用 Live Server。

不要直接双击 `index.html`；模型与声音都要通过本地 HTTP 服务加载。A-Frame、GLB、录音都在压缩包中，运行时不依赖外部 CDN。

## 操作

- WASD / 方向键：行走；鼠标：转动视角；Esc：释放鼠标。
- 靠近亮起的互动目标即可触发，无需按 E。
- 右下角 Sound 滑块调节总音量；M 键静音/恢复声音。
- `?debug=1` 显示空气墙范围。
- 普通桌面浏览器是这版全屏视觉效果的目标；头显模式未应用这套屏幕后处理。

## 代码从哪里看

| 文件 | 主要区块 | 常改参数 |
| --- | --- | --- |
| `js/app.js` | 01 总配置、02 空气墙、03 行走、04 引导灯、05 触碰、06 物体回应、07 门、08–10 体验管理 | `WORLD.start/path/objects/doors/stages`、行走速度、`overload` 曲线 |
| `js/soundscape.js` | 01 声音配置、02 混响、03 渐进曲线、04 玩家脚步与提示音 | `SOUND.layers` 中 `at/base/gain/pan/offset`；总音量 `SOUND.volume` |
| `js/sensory-fx.js` | 01 视觉逻辑、02 空间呼吸、03 失焦重影、04 眩光、05 渲染、06 终点白场 | shader 内的 `mild/strong/peak`；白场起始阈值 `.64` 与终点时间 |
| `index.html` | 场景、四道门、四个互动目标、安静空间与玩家 | 物体外形、尺寸、材质 |
| `style.css` | 开场、提示、过渡、全屏白色层、音量条 | 字体、布局、界面颜色 |
| `audio/CREDITS.md` | 真实录音来源、许可与剪辑说明 | 将来换成自己在校园录制的声音时，更新这里 |

声音的 `at` 指在多少过载程度开始加入该层；`gain` 是后段增加量，不是电脑系统音量。`offset` 让相同录音从不同位置开始，形成不同组的交谈。

## 研究与创作定位

先前参考：Weinel, Cunningham & Pickles，*Deep Subjectivity and Empathy in Virtual Reality: A Case Study on the Autism TMI Virtual Reality Experience*。

[作者发表列表](https://www.jonweinel.com/publications) · [论文 DOI](https://doi.org/10.1007/978-3-319-73356-2_11) · [研究机构页面](https://researchportal.lsbu.ac.uk/en/publications/deep-subjectivity-and-empathy-in-virtual-reality-a-case-study-on--2/)

这一版把“日常场景里的信息越来越难筛选”作为创作方向。具体的多层录音、同色重影、失焦和全白转场，是本项目的声音与视觉隐喻，不是论文给出的标准效果参数，也不代表所有自闭症人士的实际感知。

## 检查范围

v4 在 Chromium 中测量实际输出的耳鸣频谱与音量变化，确认开头静音、中后段渐强、总音量静音与结尾淡出，并检查后段着色器与摄像机高度。此前版本在 Chromium 中检查模型与三个音频文件加载、七层音频混合参数的逐渐增加、静音和音量控制、行走方向、四个互动的顺序解锁、门碰撞、路线连续性、全屏白场和结尾声音淡出。软件渲染检查不代表你的电脑上的实际帧率。
